Sample Apps

9 Xcode projects, one per module, with a screen for each of the course's 72 lessons

Start here

Every lesson, running on an iPhone

Each sample is a complete Xcode project for one module of the course. Its home screen lists that module's lessons in course order, and every lesson opens a screen of live demos. Each demo card is titled after the course step it illustrates, and every line of code is commented.

Open and run a sample

  1. Download the course repository as a ZIP, unzip it and open the samples folder.
  2. Open a sample's folder and double-click its .xcodeproj file.
  3. Choose an iPhone simulator in the run destination menu.
  4. Press Run (Command-R). Press Command-U to run its tests.

Jump straight to a lesson

  1. Choose Product > Scheme > Edit Scheme, then Run > Arguments.
  2. Add the two arguments -lesson and a lesson number, such as 4.3.
  3. Run again: the app opens on that lesson. Untick the arguments to return to the list.

On your own iPhone

  1. Select the project, then the app target, then Signing & Capabilities.
  2. Set Team to your Personal Team.
  3. Change the bundle identifier from com.example to your own prefix, such as com.yourname, because identifiers must be unique.
