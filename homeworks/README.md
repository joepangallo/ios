# Homeworks

Student editions of the course homework assignments. Each file is a single self-contained HTML page — open it in any browser, no server or login needed.

- **Homework 1** — `ios-homework-1-modules-1-4.html`: graded core (100 pts) covers Modules 0–3 as the course numbers them, plus a separately scored Module 4 SwiftUI extension (25 pts) and +4 bonus.

These student editions grade themselves with salted hash checks, so the files contain **no readable answer key**. The teacher editions (with keys) are held by the instructor and are not in this repo.
